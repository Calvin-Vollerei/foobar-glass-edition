# foobar2000 中文 · 毛玻璃（便携版）

基于一份官方 `foobar2000 v2.26.2 x64` 安装复制出来的**独立便携副本**，原安装一个字节都没改。

- **界面**：换成 WebView2 UI + 官方默认主题，**主界面全中文**（导航、媒体库、播放列表、设置、歌词面板、右键菜单都由主题提供，主题内置 1600+ 条简体中文文案）
- **毛玻璃**：窗口材质用 DWM **Acrylic（亚克力）**，真实模糊背后的壁纸/窗口，不是画上去的假半透明；深色模式是半透明玻璃 + 播放胶囊磨砂，浅色模式是更亮的半透明（卡片磨砂、对话框遮罩同样生效）
- **绿色**：配置、曲库索引、主题都在本目录 `profile\` 里，不写注册表，删文件夹即卸载

## 启动

双击 **`启动 foobar2000（中文·毛玻璃）.lnk`**（`启动.bat` 是备用入口，或直接双击 `foobar2000.exe`）。

首次启动会重建 WebView2 缓存（打包时剔除了约 80 MB 缓存），要几秒才出界面。
默认**最小化到托盘**（设置 → 常规 → 托盘 可关）；窗口不见了就看任务栏右下角托盘图标。

## 毛玻璃是怎么保证的

主题在挂载时会自己重设一次窗口材质（会把材质清成「无」），所以重启就掉玻璃。
`profile\webview-ui\default\fe\0.3.0\glass-acrylic.js` 是我加的**看门狗 + 皮肤脚本**，做四件事：

1. 每 0.9 秒检查 `window.getBackdropPolicy()`，发现材质不是 `acrylic` 就补回去；
2. **深色模式**把 Fluent 的中性面色（`#292929` / `#1f1f1f` / `#141414` …）改写成半透明，
   内容区、卡片、列表、侧栏、播放栏一起透出背后的模糊；
3. 两种模式下内容卡片都保持磨砂（模糊加在主题自己的 `_edge_` 层上），顶部工具栏按钮是半透明胶囊，
   对话框、弹层的遮罩压暗并加模糊；
4. 把设置里的「窗口背景」整卡和「胶囊背景模糊」一行隐藏掉——这两项已经由脚本接管；
   同一组里的「播放栏位置」三选一（窗口底部 / 标题栏 / 胶囊）仍然可用。

**深浅色分别做了什么：**

- **深色模式**：半透明玻璃 + 播放胶囊磨砂（玻璃感最明显）；
- **浅色模式**：更亮的半透明——卡片磨砂、胶囊磨砂、对话框遮罩同样生效；
- **对话框**：背景压暗 55% + 24px 模糊（深浅色一致），面板保持 94% 不透明，所以字还是清楚的。

想调效果就改 `profile\webview-ui\default\fe\0.3.0\glass-acrylic.js` 开头的常量：

```js
var GLASS_BG      = 0.16;   // 深色外壳 / 背景透明度
var GLASS_CARD    = 0.30;   // 深色 Fluent 中性面色（卡片 / 列表 / 菜单）
var CAPSULE_BLUR  = 'blur(30px) saturate(175%)';

// 深色：_root_obom2 rgba(28,28,28,0.16)    _fill_td4ka rgba(20,20,20,0.42)
// 浅色：_root_obom2 rgba(232,232,232,0.38)  _fill_td4ka rgba(255,255,255,0.28)
// 卡片模糊（两种模式）：_edge_td4ka blur(24px) saturate(150%) brightness(1.05)
// 对话框：遮罩 rgba(0,0,0,0.55) + blur(24px) saturate(130%)；面板 深 rgba(24,24,24,0.94) / 浅 rgba(252,252,252,0.94)
// 播放胶囊：深色 rgba(14,14,14,0.34) / 浅色 rgba(250,250,250,0.34)，+ blur(30px) saturate(175%)，定位必须是 absolute
// 顶栏按钮胶囊：深 rgba(20,20,20,0.55) / 浅 rgba(255,255,255,0.62)，blur(18px) saturate(140%)
```

## 像素级验证（不是"看着像"）

把一块**红/蓝大色块棋盘**垫在窗口后面，再取窗口内部空白处的屏幕像素：

| 状态 | 采样色（示例点） | 区域均值 RGB |
| --- | --- | --- |
| 关材质 | (28, 32, 31) 中性灰 | 27.8 / 31.8 / 30.8 |
| 开 Acrylic | (43, 34, 43) 偏紫 | **54.3 / 40.6 / 54.4** |

开材质后 R、B 通道比 G 高约 13–26 —— 红+蓝被模糊混合后的颜色透上来，
说明窗口区域确实透出并模糊了背后内容。

## 已知限制（如实说明）

1. **foobar2000 自身的原生对话框仍是英文**：`Ctrl+P` 首选项树（标题就是 `Preferences: ...`）、属性页、部分消息框属于 Win32 原生资源，
   不在 WebView2 主题里，改它们要动 `foobar2000.exe` / `foo_ui_std.dll` 的字符串并重定位引用，本次没有做。
2. 组件自带首选项页（`首选项 → Display → WebView2 UI`）语言跟随 foobar2000 本体，也是英文。
3. 主题带「在线歌词 / 在线音乐」开关（默认关）；开了之后会向网易云/酷狗等接口发送曲名、艺人、专辑、时长（不发文件路径）。
4. 毛玻璃明不明显取决于**背后的东西**：背后是深色壁纸时很含蓄，背后有亮色/彩色内容时非常明显——这是亚克力的物理特性，不是没生效。
5. **浅色模式的玻璃比深色浅**：两种模式都有玻璃，但浅色模式整体更亮、更轻（避免浅色字压在深色亚克力上不可读）；想要玻璃感最明显就用深色模式。
6. **背景来源请保持「系统材质」**：主题的「背景来源 = 图片」在启动时会报 `背景图片读取失败`，请保持 `背景来源 = 系统材质`、`材质 = Acrylic`。
7. **在线音乐首次使用需要联网**：主题的在线音乐后端不随包携带，第一次用要在线下载（约 120 MB）。
8. **标题栏模式的播放栏由主题按窗口宽度决定**（1008 px 断点），与是否全屏无关；普通窗口想要底部胶囊，请在 `播放栏位置` 选「胶囊」。

## 背景图片读取失败（已知）

主题自带的「背景来源 = 图片」模式启动时会报 `背景图片读取失败`，并可能把窗口材质一起丢掉。
脚本不再去修它（硬改容易把材质弄丢），**规避方法**就是让它保持默认：

- `背景来源 = 系统材质`
- `材质 = Acrylic`

这样不会触发这个报错，毛玻璃也正常。
